# Project AURA – UR5 Energy-Optimized Manipulator Framework

## Overview
This project aims to develop an energy-efficient motion planning and control framework 
for a 6-DOF UR5 industrial manipulator.

## Current Phase
Sprint 1 – Kinematic Modeling & Workspace Validation

## Objectives
- Implement DH parameter-based kinematic model
- Validate forward kinematics
- Analyze workspace
- Perform singularity analysis
